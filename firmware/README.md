# קוד – חנוכיית "גלי העלייה" (ESP32-S3 SuperMini)

## לפני הצריבה הראשונה: קובץ הסודות
מעתיקים את `include/secrets.example.h` לקובץ חדש בשם `include/secrets.h`, וממלאים בו:
- `AP_PASS`: הסיסמה של רשת ה-WiFi של החנוכייה (לפחות 8 תווים).
- `OWNER_PIN`: קוד ה-PIN לשליטה בבלוטות' (4 עד 8 ספרות).

הקובץ `secrets.h` **לא עולה ל-GitHub**, כך שהסיסמה וה-PIN נשארים פרטיים.

## פתיחה ב-VS Code
1. מתקינים את התוסף **PlatformIO IDE**. אם התיקייה נפתחת, VS Code גם יציע להתקין אותו.
2. File → Open Folder → בוחרים את התיקייה `firmware`.
3. מחברים את ה-SuperMini ב-USB-C ולוחצים על **Upload** (→) בשורת הסטטוס למטה.
   אם הצריבה לא מתחילה: מחזיקים את כפתור **BOOT**, לוחצים **RST**, משחררים את BOOT ומנסים שוב.
4. **Serial Monitor** (🔌) מציג את כתובת הדף והודעות מהבקר.

## מבנה
| קובץ | מה יש בו |
|---|---|
| `include/config.h` | **כל ההגדרות**: פינים, מספר הלדים בכל גל, סדר צבעים, הגבלת זרם, WiFi, שעת ההדלקה |
| `src/main.cpp` | מצבים, לחצן, מגע, בחירת הלילה |
| `src/ceremony.cpp` | אנימציית ההדלקה |
| `src/lights.cpp` | האפקטים ברצועות + שליטה בנרות |
| `src/hebcal.cpp` | חישוב לוח עברי: איזה לילה של חנוכה היום |
| `src/web.cpp`, `src/web_page.h` | דף השליטה דרך WiFi |
| `src/ble.cpp` | שליטה בבלוטות' מדף הפרויקט (Web Bluetooth) |
| `include/secrets.h` | סיסמת WiFi וקוד PIN (פרטי, לא ב-GitHub) |

## מצבים
| מצב | מה קורה |
|---|---|
| **אוטומטי** (ברירת מחדל) | לפי התאריך העברי. בכל ערב ב-16:30 החנוכייה "מדליקה" את הלילה הנוכחי. מחוץ לחנוכה עוברת להדגמה |
| **ידני** | לילה קבוע שבוחרים |
| **כל הנרות** | 8 נרות ושמש |
| **הדגמה** | עוברת בין לילות 1 עד 8 עם אנימציית הדלקה. מתאים לתערוכה |

**טקס ההדלקה**: האור עולה בתורן והשמש נדלק. אחר כך, לכל נר לפי הסדר ההלכתי (מהנר החדש, השמאלי, ימינה), אור עולה בגל שלו והנר נדלק בראשו.
גלים שהנר שלהם דולק זוהרים בצבע חם. השאר נשארים בצבע של ים.

## שליטה
- **לחצן**: לחיצה קצרה עוברת ללילה הבא (1 עד 8, אחר כך כל הנרות). לחיצה ארוכה, יותר משנייה, מחזירה למצב אוטומטי.
- **מגע** בעיגול שעל הבסיס: הטקס המלא, כולל "האונייה מגיעה" (גל אור בחלון הבסיס).
- **בלוטות'** (אנדרואיד ומחשב, בדפדפן Chrome): פותחים את דף הפרויקט, יורדים ל"לוח בקרה", לוחצים "התחבר בבלוטות'" ומקלידים את ה-PIN.
  הדף שומר את ה-PIN, וכל התחברות שולחת לחנוכייה גם את השעה מהטלפון.
- **WiFi** (גם באייפון): מתחברים לרשת **Hanukkiah** (הסיסמה מ-`secrets.h`) ונכנסים ל-**http://192.168.4.1**.
  - אפשר לבחור מצב, לילה, בהירות וערכת צבעים (ים וזהב, כחול לבן, זהב חם, קשת).
  - **השעון**: כשאין אינטרנט, השעה נלקחת מהטלפון כשנכנסים לדף. כדאי להיכנס לדף פעם אחת אחרי כל הדלקה של החנוכייה.
  - אפשר גם לחבר את החנוכייה ל-WiFi של הבית. אז השעה מגיעה מהאינטרנט, והדף זמין גם בכתובת http://hanukkiah.local

## אחרי ההרכבה
- סופרים את הלדים בכל גל ומעדכנים את `ARM_LEDS`, לפי הסדר L4 L3 L2 L1 R1 R2 R3 R4.
  אותו דבר עבור `BASE_LEDS` ו-`MAST_LEDS`.
- אם אדום וירוק מתחלפים, משנים את `ARMS_COLOR_ORDER` או `COB_COLOR_ORDER` (למשל ל-RGB).
- **רצועת ה-COB**: בחלק מהרצועות מסוג COB כל "פיקסל" מורכב מכמה לדים. אם האנימציה במקום הזה נראית מתוחה או מקוצרת,
  סופרים כמה פיקסלים שולטים באמת (מדליקים אחד-אחד) ומעדכנים את המספרים.

החישוב של תאריכי חנוכה נבדק מול התאריכים האמיתיים של 2021–2035. השנה (תשפ"ז) הנר הראשון הוא בערב **4 בדצמבר 2026**.
