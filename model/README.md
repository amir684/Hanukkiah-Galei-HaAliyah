# חנוכיית "גלי העלייה" – מודל להדפסה

זרועות החנוכייה הן 8 גלים שזוהרים מבפנים. הם יוצאים מאונייה, והתורן שלה הוא השמש.
המודל כולו פרמטרי וכתוב בקובץ `hanukkiah.scad` (OpenSCAD).

## מידות
| | |
|---|---|
| רוחב | 234 מ"מ |
| עומק בסיס | 90 מ"מ |
| גובה עד ראש השמש (כולל נר + להבה) | כ-335 מ"מ |
| גובה 8 הנרות (כולם באותו גובה) | כ-290 מ"מ |

## איך האור עובד
- **גלים (8 זרועות)**: לכל זרוע יש חריץ בגב. רצועת WS2812 2020 (2.7 מ"מ) נכנסת לחריץ, יושבת על מדף, והלדים מופנים קדימה.
  לפני הלדים יש 4 מ"מ אוויר ו-1.2 מ"מ PLA לבן, ולכן הגל זוהר כקו רך ולא כנקודות.
  אורך הרצועה בכל זרוע, בערך: 127, 129, 132, 137 מ"מ (20–21 לדים).
- **תורן**: רצועת COB 5 מ"מ ישרה (בלי כיפוף), באורך כ-180 מ"מ.
- **בסיס**: רצועת COB ישרה, מודבקת על צלע פנימית 20 מ"מ מאחורי החלון. היא מאירה את פאנל הגלים ואת הכיתוב "נס גדול היה פה".
- **נרות**: נורת הלהבה (38 מ"מ: להבה 13.8 מ"מ רוחב + זנב PCB של 9×11 מ"מ עם שבב) נכנסת לחריץ 9.6×3.6×12 מ"מ בראש הנר.
  כל ה-PCB והשבב מוסתרים בתוך הנר, ורק הלהבה (כ-27 מ"מ) יוצאת מעליו, כשהצד הרחב פונה קדימה.
  מתחת ללוח יש חלל בקוטר 8 מ"מ לנקודות ההלחמה. מלחימים את שני החוטים לפדים *לפני* ההכנסה, ומעבירים אותם דרך חור של 5 מ"מ
  בתוך הנר, לתוך הזרוע, ומשם לחלל שמאחורי האונייה. ראה `renders/candle_section.png`.

> שים לב: רצועת ה-2.7 מ"מ מתכופפת בזרוע "בצד" (בתוך המישור של הרצועה). הקשתות רחבות, כך שזה עובד,
> אבל צריך להכניס אותה לאט ולהצמיד בהדרגה. לא לקפל בבת אחת.

## הרכבה (מכנית)
1. הנרות נכנסים לשקעים בראש כל גל (הדבקה קלה).
2. הפינים בתחתית ה-fan נכנסים לחריצים בגג הבסיס. החוטים יורדים דרך הפתח שביניהם.
3. גוף האונייה מודבק על חזית ה-fan, על הבסיס. המפרשים מודבקים משני צדי התורן.
4. `base_window` מודבק מבפנים לחלון הקדמי, עם הכיתוב כלפי חוץ. כדאי לצבוע את האותיות בזהב.
5. רצפת הבסיס נסגרת ב-3 ברגי M3×10 (קודחים ישר לפלסטיק).

בבסיס יש גם: עיגול מגע בגג מימין (חיישן TTP223 מודבק מתחתיו, דרך 1.5 מ"מ פלסטיק), חור לכפתור 12 מ"מ בגב,
פתח ל-USB-C בגב, ועמודונים ללוח חורים 50×70 שעליו יושב ה-ESP32-S3 SuperMini.

## שינוי מידות
כל המידות בראש הקובץ `hanukkiah.scad`: גובה הנרות (`HC`), גובה השמש (`HM`), מיקומי הנרות (`ARM_XC`),
צורת הגלים (`BEZ`), עובי (`T`). אחרי שינוי מייצאים מחדש:
```
openscad -o stl/fan.stl -D part=\"fan\" hanukkiah.scad
```
תצוגה מקדימה עם האור: `-D LIT=true`.
